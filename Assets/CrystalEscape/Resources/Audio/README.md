# Replace the placeholder audio

The game runs with synthesized placeholder tones, but the assignment requires the Week 6 audio workflow.

Export your generated audio as WAV or OGG and place the files here with these exact names:

- `BGM.wav` — looping background music
- `Pickup.wav` — crystal reward sound
- `Hurt.wav` — damage sound
- `Win.wav` — victory sound
- `Lose.wav` — loss sound

Unity will automatically use these files instead of the runtime placeholder tones.
